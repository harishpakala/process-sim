# Deterministic compiler validation
The fixture validator was reported passing all 11 cases on 42 triples. This separate script selects the intended paths manually, resolves each edge and property from the real schema index, and calls the production single-domain compiler. It compares RDF term bags against the reference queries locally. It deliberately supplies oracle-selected records, not actual LLM or planner validation output; it isolates compiler behavior only. Run python benchmarks/modelsward2027/ownership_challenge/validate_compiler.py from the repository root with the project installed. No live GraphDB or LLM required. Script execution pending. No changes to production compiler or historical benchmark.
