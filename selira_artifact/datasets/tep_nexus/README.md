# TEP-Nexus research dataset

This dataset supports cross-domain semantic interoperability and lifecycle contract evaluation based on the Tennessee Eastman Process benchmark. It is not a validated physical plant model.

The six Turtle files represent AssetInventory, ProductCatalog, DEXPI, ECAD, EngineeringBOM and OPC UA Connectivity. The integrated lifecycle workload uses five of these; the connectivity file is retained as part of the dataset inventory.
