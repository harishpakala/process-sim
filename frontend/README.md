# TEP Nexus frontend

Vue 3 + TypeScript + Vite starter for the process-sim semantic digital twin.

## Run

```sh
cd frontend
npm install
npm run dev
```

## Status

This is an offline UI prototype. No live TEP simulation, GraphDB, SAFSL or LLM service is connected. Schematic lines are illustrative, not verified DEXPI piping. Future API integration should use the existing process-sim TEPAdapter, not implement TEP equations in the frontend.
