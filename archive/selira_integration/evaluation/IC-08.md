Run from repository root with src on PYTHONPATH:
```powershell
$env:PYTHONPATH = "$PWD\\src"
python selira_integration/evaluation/multi_contract_lifecycle.py
```

The script first rejects the unmodified real baseline, checks independent/SHACL agreement, records per-node identifiers and input hashes, then constructs a controlled in-memory comparison graph by replacing inconsistent local tags with authoritative suffixes. This is an experimental counterfactual, not an engineering correction. It exercises local and authoritative identifier changes, OPC UA isolation, missing attestations and full fallback. Selective counts are logical reassessment counts, not incremental SHACL timings. Historical results are retained; the new output is multi_contract_lifecycle_ic08.json. Commit the generated result only after successful execution.
